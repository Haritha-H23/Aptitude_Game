# Aptitude Game – Interactive Practice Application

## Overview

The Aptitude Game is an interactive application designed to help users practice and improve their aptitude skills through timed questions and instant feedback. It focuses on enhancing problem-solving speed, accuracy, and logical thinking.

---

## Tech Stack

* Frontend: HTML, CSS, JavaScript 
* Backend: Firebase
* Database: Firebase

---

## Features

* Multiple-choice aptitude questions
* Timer-based question solving
* Instant feedback on answers
* Score tracking system
* Simple and user-friendly interface

---

## Game Flow

1. User starts the quiz
2. Questions are displayed one by one
3. User selects an answer within a time limit
4. System evaluates the answer instantly
5. Final score is displayed at the end

---

## Categories Covered

* Percentage
* Ratio and Proportion
* Time and Work
* Basic Arithmetic

## Project Structure

* components/ – UI components

## How to Run

1. Clone the repository
2. Navigate to the project directory

```bash
npm install
npm start
```

### If using HTML/CSS/JS:

Open the index.html file in a browser
